Privacy Policy

Josh Personal Google CLI

Last updated September 13, 2026

This policy covers a set of personal command-line tools that Josh Davidoff uses to work with his own Google account data. The tools are not a product, are not offered to anyone else, and have exactly one user.

What the tools do

They access Gmail, Google Drive, and Google Calendar data belonging to the account that authorizes them, so that it can be searched, organized, exported, and backed up from a personal computer. Typical uses are bulk-labeling mail, exporting messages and files for archival, and reading calendar agendas in a terminal.

What data is accessed

  • Gmail messages, labels, and attachments
  • Google Drive files and their metadata
  • Google Calendar events and calendar lists
  • The email address of the authorizing account, used only to confirm the tools are acting on the intended account

Where the data goes

Nowhere. The tools run locally on Josh Davidoff's own computer and communicate only with Google's APIs. There is no server, no hosted backend, no analytics, and no third party that receives any of this data. Data that is exported is written to local disk and stays there.

Sharing and sale of data

No data accessed by these tools is sold, shared, transferred, or disclosed to anyone. There is no advertising, profiling, or training of machine-learning models on this data.

Credentials and storage

OAuth tokens issued by Google are stored in files readable only by the local user account on that computer. They can be revoked at any time from the Google Account permissions page, which immediately ends the tools' access.

Retention

Nothing is retained by any service, because no service is involved. Locally exported copies persist on the personal computer until deleted by hand.

Children

The tools are not directed at children and are used only by their sole adult operator.

Changes

If the tools change in a way that affects this policy, this page will be updated and the date above revised.

Site analytics

Separately from the tools above, joshdavidoff.com uses GoatCounter to count page views. It records the page visited, the referring site, browser type, and screen size. It sets no cookies and does not store IP addresses; visitors are counted using a daily rotating hash that cannot be linked across days. That data goes to GoatCounter and nowhere else.
