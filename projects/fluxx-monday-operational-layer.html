Case study

Fluxx to Monday operational layer

Grant tasks from Fluxx show up on Monday boards the team uses every day, and Fluxx stays the system of record.

The problem

Fluxx holds the grants data, but it has no project management tools. The team needed to plan around reports, agreements, and payments without the data drifting away from Fluxx.

What I built

A controlled operational layer in Monday: records in certain states sync from Fluxx into custom Monday boards, and designated fields write back. Staff get a notification when a report or agreement changes state and can plan from views that used to be locked inside Fluxx. Nobody needs an emotional-support shadow spreadsheet.

Object rules

ObjectSystem of recordOperational mirrorNotes
Grants / proposals Fluxx Monday, SharePoint, Power BI Edited only in Fluxx
Reports Fluxx Monday Only state and due date write back
Agreements Fluxx Monday State column only
Payments Fluxx Monday, SharePoint Power BI reads from the SharePoint list, so it has to stay accurate
Board prep planning Monday Outlook, dashboards Planning data only, not grants data
Meeting scheduling Monday Outlook, staging folders, board packets High manual oversight
Receipts Monday QuickBooks (manual) Intake is automated and reconciliation is manual
Cash flow visuals Fluxx SharePoint → Power BI Check the SharePoint list before trusting the charts
